# HackOS — конструктор загрузочного дистрибутива для пентеста

Это **НЕ готовый .iso**, а полный набор конфигов и скриптов, из которого
собирается настоящий загрузочный образ на базе Debian через `live-build`.
Отдай этот .zip другому ИИ или собери сам на Linux — получится рабочий `.iso`.

> ВАЖНО ПРО ЗАКОННОСТЬ. Все инструменты — ТОЛЬКО для легального
> использования: свои системы, учебные лаборатории (HackTheBox, TryHackMe,
> DVWA) или работа по письменному разрешению. Атаки на чужие системы
> и пробив людей — незаконны.

## Как собрать .iso

Нужна машина/ВМ с Debian или Ubuntu и интернет:

```bash
sudo apt update
sudo apt install -y live-build
cd HackOS
sudo ./build.sh
```

Через 20–60 минут появится `hackos-amd64.hybrid.iso`.

## Поведение при загрузке

- Система загружается СРАЗУ В КОНСОЛЬ (автовход на tty1).
- Сразу видно меню; набери `hackos` — список команд.
- Графический рабочий стол — командой `startx`.
- Сеть/интернет поднимаются автоматически (NetworkManager).

## Свои команды

- `hackos` — меню/справка
- `hackos-net` — сетевая инфо + тест интернета
- `hackos-scan <цель>` — скан портов (nmap)
- `hackos-recon <домен>` — разведка по домену (whois/dns/http)
- `hackos-search "запрос"` — обычный поиск в интернете
